# App Review notes

Bottom line: a reviewer has no Audiobookshelf server, and without being told
what to do they will open Firelight, find a sign-in screen they cannot pass,
and reject it under Guideline 2.1 as non-functional. The notes exist to point
them at **"Look around first"** on the first screen. Everything else is
secondary.

Paste the block below into App Store Connect → the version → **App Review
Information → Notes**. It is 1,450 characters, well inside the 4,000 limit.

---

```text
Firelight is an unofficial, open-source client for Audiobookshelf, a
self-hosted audiobook and ebook server. It is not affiliated with the
Audiobookshelf project.

NO SERVER IS NEEDED TO REVIEW THIS APP

Firelight connects to a server the user runs on their own hardware, so there
is no account for us to give you and nothing to sign into. On the first
screen, tap "Look around first" (the binoculars button).

That opens a small built-in sample library, and every screen then behaves as
it would against a real server: shelves and search, the audio player with
chapters, speed and a sleep timer, the EPUB and PDF reader, the comic reader,
and offline downloads. Nothing is downloaded from the network and no server
is contacted.

NO ACCOUNTS

There is no sign-up and no account of ours. We operate no server and no
service. The app talks only to the server address a user types in.

IN-APP PURCHASES

Settings > Support Firelight. The four items are tips. Firelight is free,
every feature is included for everyone, and a tip unlocks nothing and changes
nothing in the app.

PRIVACY

No analytics, no advertising, no tracking, no third-party SDKs and no crash
reporting. The App Privacy label is "Data Not Collected", and that is
literal.

SAMPLE LIBRARY CONTENT

Public-domain texts, cover art generated by us, and narration synthesised
with Apple's speech synthesiser. No third-party copyrighted material ships
inside the app.

Source code: https://github.com/scwill12/firelight
```

---

## Why it says what it says

- **"Look around first" is quoted exactly**, because it is the real button
  label in `OnboardingView.swift` and a reviewer following an invented label
  gives up. The icon is named too, since the label alone is easy to miss.
- **"Unofficial" and "not affiliated" lead**, because the app is a client for
  someone else's open-source project and the name Audiobookshelf appears
  throughout the listing. Saying so first removes the question.
- **The tips are explained as unlocking nothing.** Tips are permitted, but a
  reviewer who assumes they gate features will test for a paywall that does
  not exist. The same sentence is already on each product's own review note.
- **"Data Not Collected" is restated** so the privacy answer and the binary
  agree on the record.
- **No demo account is offered**, because there is nothing to sign into. Leave
  "Sign-in required" unchecked; filling in a fake demo account is worse than
  leaving it empty.
